One 1024×1024 editorial infographic summing up world news of Tuesday 17 November 2026: Ukraine knocks out the Crimea bridge road span; Iran fires drones at a US radar base in Bahrain; Trump lands in Manila ahead of a confirmed Xi–Trump–Putin summit in Shenzhen; Nvidia beats on $115.8bn sales in its first report since Jensen Huang resigned; the Knesset ousts a Netanyahu ally as speaker; and a French public-sector strike draws 146,000 onto the streets. The image is drawn in code (`draw_entry.py`, Pillow + Liberation Sans) from reporting published that day by Reuters, AP, Bloomberg, Al Jazeera, Outlook India and Just Security; `main.ts` copies the finished `entry.png` to `/output/entry.png`, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
